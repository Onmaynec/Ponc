# Ponc 1.5.0 — Power-Up Arena

Ponc — интерактивная браузерная аркада на Canvas 2D с физикой фиксированного шага, соперником-компьютером, локальным режимом на двоих и усилениями во время розыгрыша. Никакого сервера и регистрации для локального матча не требуется.

## Запуск

Нужен Node.js 22.12+ и npm 10+. Запустите:

```bash
git clone https://github.com/Onmaynec/Ponc.git
cd Ponc
npm ci
npm run dev
```

**Обратите внимание:** версия 1.5.0 до слияния PR доступна в ветке `feature/powerup-arena-1.5`. Чтобы переключиться в неё после клонирования, выполните `git fetch origin && git switch -c feature/powerup-arena-1.5 origin/feature/powerup-arena-1.5`.

## Как играть

1. Выберите режим: против компьютера (Новичок / Стандарт / Эксперт) или локально на двоих.
2. Выберите правила: Классика до 5/7/11/15 очков, Решающее очко или На время (90 секунд активной игры, при ничьей овертайм до первого очка).
3. Включите **Силовые капсулы**, чтобы ловить бонусы прямо на поле. Можно оставить классический матч без них.
4. Отбивайте мяч ракеткой и побеждайте по выбранным правилам. При полной победе сохраняется результат одиночного матча в браузере.

### Управление

| Режим                      | Управление                                  |
| -------------------------- | ------------------------------------------- |
| Одиночный, ПК              | Мышь или стрелки ↑ / ↓                      |
| Локально вдвоём, ПК        | Игрок 1: W/S; игрок 2: ↑/↓                  |
| Одиночный, сенсорный экран | Ведите пальцем по полю                      |
| Вдвоём, сенсорный экран    | Каждый ведёт пальцем по своей половине поля |
| Пауза                      | Esc или кнопка «Пауза»                      |
| Перезапуск                 | R или кнопка «Начать заново»                |

Игра автоматически приостанавливается при потере фокуса вкладки.

### Усиления

Бонус получает игрок, который **последним отбил мяч**; чтобы собрать капсулу, нужно попасть по ней мячом. Усиления работают как против ИИ, так и во время игры на двоих.

- **+ XL-ракетка:** высота ракетки увеличивается с 80 до 120 на 7 секунд активной игры.
- **» Турбо:** мяч ускоряется до 35%, но не больше 600 пикселей в секунду.
- **◆ Энергощит:** защищает свои ворота 9 секунд или до одного пропущенного удара. Мяч отражается, очко не засчитывается.

Новые капсулы появляются через 3 секунды активного розыгрыша и затем через 5 секунд после исчезновения/сбора. Они живут 8 секунд. Эффекты сбрасываются между розыгрышами и при перезапуске.

## Достижения и оформление

Пять достижений по одиночным матчам: первая победа, 5 и 10 побед, победа над экспертным ИИ и победа всухую. Статистика последних 50 завершённых матчей, выбранные звуки и тема оформления сохраняются локально в `localStorage` и не синхронизируются между устройствами. Оформления: Неон, Ретро и Монохром. Звуки синтезируются в браузере через Web Audio, внешних файлов нет.

## Разработка и проверка

| Команда                | Описание                                                       |
| ---------------------- | -------------------------------------------------------------- |
| `npm run dev`          | Сервер для разработки Vite                                     |
| `npm run build`        | Сборка в `dist/`                                               |
| `npm run preview`      | Просмотр сборки                                                |
| `npm run lint`         | ESLint                                                         |
| `npm run format:check` | Prettier                                                       |
| `npm test`             | Модульные и интеграционные тесты Node.js                       |
| `npm run test:e2e`     | Playwright (нужен Chromium: `npx playwright install chromium`) |

```text
src/
├── config/       параметры размеров, скоростей и правил
├── core/         симуляция, режимы, история, достижения, состояния
├── entities/     мяч и ракетки
├── systems/      физика, ИИ, ввод, усиления и синтез звуков
├── rendering/    Canvas 2D
└── ui/           DOM-интерфейс, меню, HUD и стили
```

Физика исполняется с частотой 120 Гц; интерфейс только отображает снимок состояния. На телефоне предусмотрена обработка Pointer Events и двух независимых касаний в локальном режиме.

Для развертывания на статическом хостинге: `npm run build` и публикация содержимого `dist/`. Vite настроен на относительную базу `./`.

**Ограничения:** онлайн-мультиплеер, серверные профили и общий рейтинг пока не реализованы.
