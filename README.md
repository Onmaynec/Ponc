# Ponc - Pong Game 🎮

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Полнофункциональная игра Pong, созданная на чистом HTML, CSS и JavaScript. Играйте против компьютера с интеллектуальной системой управления ракеткой.

## 🎯 Особенности

- ✅ **Управление левой ракеткой** - мышь и стрелки вверх/вниз
- ✅ **Компьютерный противник** - автоматическое управление правой ракеткой
- ✅ **Отскок мяча** - реалистичная физика отскока от стен и ракеток
- ✅ **Обнаружение столкновений** - точное определение столкновений со всеми объектами
- ✅ **Система подсчета очков** - отображение текущего счета обоих игроков
- ✅ **Адаптивный дизайн** - красивый и чистый интерфейс

## 🚀 Быстрый старт

### Способ 1: Прямой запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Onmaynec/Ponc.git
   cd Ponc
   ```

2. Откройте файл `index.html` в браузере:
   - Двойной клик на файл, или
   - Перетащите файл в браузер

### Способ 2: Локальный сервер (рекомендуется)
```bash
# Если у вас установлен Python 3:
python -m http.server 8000

# Или для Python 2:
python -m SimpleHTTPServer 8000
```

Затем откройте браузер и перейдите на `http://localhost:8000`

## 🎮 Как играть

### Управление
- **Мышь** - движение левой ракетки вверх/вниз (следует за мышью)
- **Стрелка ⬆️** - левая ракетка вверх
- **Стрелка ⬇️** - левая ракетка вниз
- **R** - перезагрузить игру (сброс счета и мяча)

### Правила
1. Отскочьте мяч от своей ракетки (слева)
2. Не дайте мячу пройти слева направо
3. Компьютер будет защищать правую сторону
4. Первый набравший 11 очков выигрывает раунд

## 🛠️ Технические детали

### Используемые технологии
- **HTML5** - структура приложения
- **CSS3** - стилизация и анимации
- **JavaScript (ES6+)** - игровая логика
- **Canvas API** - отрисовка игры

### Основные компоненты

#### Мяч (Ball)
- Позиция, скорость, размер
- Отскок от стен и ракеток
- Сброс позиции при выходе за границы

#### Ракетки (Paddles)
- Левая ракетка - управляется игроком
- Правая ракетка - управляется AI
- Collision detection

#### Система AI
- Компьютер отслеживает положение мяча
- Автоматически перемещает ракетку
- Может быть настроена сложность (скорость AI)

#### Обнаружение столкновений
- Столкновение мяча с верхней/нижней стеной
- Столкновение мяча с ракетками
- Выход мяча за левую/правую границу (цель)

## 🎨 Персонализация

Вы можете легко изменить игру, отредактировав параметры в `js/game.js`:

```javascript
// Размер мяча
const BALL_SIZE = 8;

// Размер ракетки
const PADDLE_WIDTH = 10;
const PADDLE_HEIGHT = 80;

// Скорость игры
const INITIAL_BALL_SPEED = 5;

// Скорость AI
const AI_SPEED = 4.5;
```
