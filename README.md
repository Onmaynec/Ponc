# Ponc — Pong Game 🎮

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Ponc — браузерная игра Pong на чистом HTML, CSS и JavaScript. Игрок управляет левой ракеткой, компьютер — правой.

## Версия 1.0.1 — Stability Hotfix

Обновление 1.0.1 стабилизирует жизненный цикл матча, управление и столкновения:

- матч завершается при достижении 11 очков;
- добавлены состояния `MENU`, `COUNTDOWN`, `PLAYING`, `PAUSED`, `GAME_OVER`;
- физика обновляется только во время `PLAYING`;
- перед первой подачей и после каждого гола выполняется двухсекундный отсчёт;
- `Esc` и кнопка управляют паузой, `R` и кнопка перезапускают матч;
- координаты указателя корректно масштабируются для Canvas любой отображаемой ширины;
- активным остаётся последний использованный тип ввода: мышь или клавиатура;
- при потере фокуса или скрытии вкладки матч автоматически ставится на паузу;
- отскок срабатывает только при движении мяча к ракетке, а мяч выносится за её границу;
- скорость мяча ограничена, горизонтальная составляющая после отскока не опускается ниже безопасного значения.

Полный перечень изменений приведён в [CHANGELOG.md](CHANGELOG.md).

## Быстрый старт

Сборка и серверная часть не требуются.

```bash
git clone https://github.com/Onmaynec/Ponc.git
cd Ponc
python -m http.server 8000
```

Откройте `http://localhost:8000` в браузере. Также можно открыть `index.html` напрямую.

## Управление

| Действие | Управление |
|---|---|
| Перемещение ракетки | мышь / указатель |
| Перемещение ракетки | `ArrowUp` / `ArrowDown` |
| Пауза / продолжить | `Esc` |
| Начать заново | `R` |

Последний использованный способ ввода остаётся активным и не перезаписывается сохранённым положением указателя.

## Правила

1. Управляйте левой ракеткой.
2. За каждый пропущенный мяч соперник получает очко.
3. Первый участник, набравший 11 очков, выигрывает матч.
4. После гола выполняется короткий обратный отсчёт перед новой подачей.

## Проверки

Автоматические проверки используют встроенный тестовый модуль Node.js и не добавляют runtime-зависимостей:

```bash
node --test tests/game.test.js
```

Рекомендуемая ручная регрессия:

- победа игрока `11:0` и компьютера `0:11`;
- повторный запуск после `GAME_OVER` без перезагрузки страницы;
- мышь при отображаемой ширине Canvas 800, 600, 400 и 320 px;
- переключение мышь ↔ стрелки в одном розыгрыше;
- автоматическая пауза при смене вкладки;
- отсутствие двойного отскока и застревания мяча;
- отсутствие ошибок и необработанных исключений в консоли.
