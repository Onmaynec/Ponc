# Ponc v1.8.0 — Precision Academy

Ponc — браузерная аркада в стиле Pong: классические матчи, режимы на время и выживание, локальная игра на двоих, Championship Circuit и новая тренировочная академия. Используются JavaScript ES Modules, Canvas 2D и Vite, физика с фиксированным шагом 120 Гц.

## Быстрый запуск

Требуется Node.js 22.12+.

```powershell
git clone -b feature/precision-academy-1.8 https://github.com/Onmaynec/Ponc.git
cd Ponc
npm ci
npm run dev
```

После объединения PR в `main` можно использовать обычную основную ветку. Адрес локального сервера появится в выводе Vite.

## Новое: Precision Academy

Выберите **Академия — 60 секунд** в меню «Правила», затем нужное упражнение:

| Тренировка | Задача | Счёт | Соперник |
|---|---|---|---|
| Меткость | Бить по подсвеченной трети правых ворот; зона меняется после каждого гола | 3 за точный удар, 1 за обычный | Стандарт |
| Контроль | Успешно отражать мяч левой ракеткой сериями | 1 за отбив, ещё 5 за каждые 5 подряд | Стандарт |
| Реакция | Отражать удары сильного соперника, не пропустив 3 мяча | 2 за отбив; 3 жизни | Эксперт |

Таймер учитывает **только активную игру**. Пауза и отсчёт до подачи не отнимают время. В «Реакции» испытание может завершиться досрочно после трёх пропущенных голов. В академии всегда одна ракетка против ИИ, классическая арена и выключенные усиления, чтобы личные рекорды оставались сопоставимыми.

Локальная таблица показывает личный максимум в каждом упражнении, общее количество сессий и последние 5 попыток. До 60 завершённых тренировок сохраняются в `localStorage`.

## Основные режимы

- **Классика** — до 5, 7, 11 или 15 очков.
- **Решающее очко** — матч до первого гола.
- **На время** — 90 секунд активной игры, при ничьей овертайм.
- **Выживание** — максимум голов до трёх пропущенных, личные рекорды.
- **Чемпионат** — три последовательных этапа: Classic 3 очка против Новичка, FLUX 5 против Стандарта, Portal 7 против Эксперта. При поражении турнир заканчивается.
- **Академия** — три независимых тренировочных упражнения, 60 секунд активного времени.

## Арены и усиления

В обычных матчах доступны Classic, FLUX (движущийся отражатель) и PORTAL (парные телепорты). Опционально включаются силовые капсулы: XL-ракетка на 7 секунд, Turbo (до +35% скорости мяча), энергетический щит на один пропущенный удар на срок до 9 секунд. Комбинации арен, правил и бонусов выбираются в меню. В чемпионате комбинации фиксированы для этапов.

## Управление

| Сценарий | Ввод |
|---|---|
| Соло, тренировки и чемпионат | Мышь, стрелки ↑ / ↓ или касание |
| Локально вдвоём | W/S у первого игрока, ↑/↓ у второго |
| Два игрока на телефоне | Независимые касания по двум половинам поля |
| Пауза | Esc или кнопка |
| Перезапуск | R или кнопка |

При скрытии вкладки и потере фокуса игра автоматически ставится на паузу.

## Прогресс

История до 50 последних матчей, пять достижений и обычный процент побед; независимые статистические таблицы Survival (30 забегов), Circuit (30 попыток, кубки) и Academy (60 тренировок). Все записи хранятся локально в браузере. Выбор правил, тренировки, арены, звука и темы восстанавливается из localStorage.

## Проверка проекта

```bash
npm ci
npm run lint
npm run format:check
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

`src/core` — логика матча и тренировки; `src/systems` — ввод, ИИ, физика, бонусы и арены; `src/rendering` — графика Canvas; `src/ui` — меню и HUD. `tests` — Node.js unit/integration, `e2e` — Playwright Chromium. Готовая статическая версия после `npm run build` лежит в `dist/`.

**Ограничения:** онлайн-мультиплеер и синхронизация данных между устройствами пока не реализованы. Без серверной части локальные рекорды не защищены от изменения пользователем.
