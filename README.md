# Ponc 1.7.0 — Championship Circuit

Ponc — браузерная аркада Pong. В ней можно играть против компьютера, локально вдвоём, выбирать правила, арены и усиления, а также участвовать в трёхэтапном чемпионате. Движок: JavaScript ES Modules, Canvas 2D, Vite, физика с фиксированным шагом 120 Гц.

## Установка и запуск

Требуется Node.js 22.12+.

```powershell
git clone -b feature/championship-circuit-1.7 https://github.com/Onmaynec/Ponc.git
cd Ponc
npm ci
npm run dev
```

После объединения PR в main для запуска можно будет клонировать обычную ветку `main`. Vite выводит адрес локального сервера.

## Правила и режимы

- **Классика:** до 5, 7, 11 или 15 очков.
- **Решающее очко:** первый гол определяет победителя.
- **На время:** 90 секунд активной игры; при равном счёте — дополнительное решающее очко.
- **Выживание:** забей максимум голов, пока не пропустишь три мяча.
- **Чемпионат (новое):** три последовательных матча с фиксированными правилами. Победа открывает следующий этап, проигрыш в любой момент завершает турнир.

### Путь чемпиона

| Раунд            | Соперник | Арена   | Игра до | Усиления |
| ---------------- | -------- | ------- | ------- | -------- |
| 1 — Квалификация | Новичок  | Classic | 3       | Нет      |
| 2 — Полуфинал    | Стандарт | FLUX    | 5       | Да       |
| 3 — Финал        | Эксперт  | Portal  | 7       | Да       |

Результаты прохождения сохраняются локально: количество попыток, число чемпионских кубков, лучший пройденный этап и история последних попыток. Чемпионат только одиночный; настройки соперников и арен меняются автоматически, после каждой победы счёт отдельного матча сбрасывается.

## Арены

- **Classic** — свободное поле без препятствий.
- **FLUX** — движущийся центральный отражатель (16 × 92, 118 ед./с), который меняет траекторию мяча.
- **PORTAL (новая)** — парные порталы телепортируют мяч друг к другу, сохраняя скорость и направление; задержка повторной телепортации 0,65 секунды.

Все три арены можно выбирать отдельно для обычных матчей, локальной игры на двоих, Survival и других режимов.

## Усиления

Необязательные капсулы, собираемые мячом и присуждаемые последнему игроку, отбившему мяч. XL-ракетка увеличивает высоту с 80 до 120 на 7 секунд; Турбо увеличивает скорость мяча до 35% (предел 600 ед./с); Энергощит защищает ворота от одной неудачной подачи в течение 9 секунд. Усиления сбрасываются между розыгрышами.

## Управление

| Тип                            | Управление                                |
| ------------------------------ | ----------------------------------------- |
| Один игрок                     | Мышь, стрелки ↑ / ↓ или касание экрана    |
| Два игрока                     | W/S (первый) и ↑/↓ (второй)               |
| Два игрока на сенсорном экране | Два независимых касания по половинам поля |
| Пауза                          | Esc или кнопка на экране                  |
| Перезапуск                     | R или кнопка                              |

## Прогресс и настройки

- До 50 последних завершённых матчей и пять последних на главной странице.
- Одиночная карьера: победы, матчи и винрейт, без результатов чемпионата и выживания.
- Пять стандартных достижений.
- Личные рекорды Survival: 30 последних попыток, топ-5, максимум очков.
- Трофеи Championship Circuit: 30 последних попыток, пройденные этапы и кубки.
- Сохранение выбора режима, арены, правил, звука и темы оформления через `localStorage` в текущем браузере.

## Разработка

```bash
npm ci
npm run lint
npm run format:check
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Структура проекта: `src/core` — логика матчей и локальных записей; `src/systems` — физика, ввод, ИИ, арены, усиления и звук; `src/rendering` — Canvas; `src/ui` — меню/HUD. Тесты `tests` на Node.js, `e2e` на Playwright. Production-сборка находится в `dist/` и может размещаться на статическом хостинге.

**Ограничения:** нет онлайн-мультиплеера, серверной проверки результатов и синхронизации между устройствами. Вся статистика хранится на конкретном устройстве.
