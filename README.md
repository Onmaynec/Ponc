# Pong Game

Полнофункциональная игра Pong на HTML, CSS и JavaScript.

## Описание

Классическая игра Pong, где игрок управляет левой ракеткой мышью и стрелками, а правую ракетку контролирует компьютер. Цель игры - набрать больше очков, отправляя мяч на сторону противника.

## Особенности

✅ **Управление левой ракеткой:**
- Мышь (вверх/вниз)
- Стрелки клавиатуры (↑/↓)

✅ **Компьютерный противник** с логикой преследования мяча

✅ **Обнаружение столкновений:**
- Мяч ↔ Ракетки
- Мяч ↔ Стены (верхняя и нижняя)
- Мяч за границами игрового поля (подсчет очков)

✅ **Система подсчета очков** в реальном времени

✅ **Отзывчивое управление** и плавная анимация

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Onmaynec/Ponc.git
cd Ponc
```

2. Откройте файл `index.html` в веб-браузере:
```bash
open index.html
# или просто перетащите файл в браузер
```

## Как играть

- **Управление левой ракеткой:**
  - Движение мышью вверх/вниз
  - Или используйте стрелки ↑ и ↓

- **Цель:** Набрать больше очков, чем компьютер

- **Мяч отскакивает** от ракеток и стен

- **Очко засчитывается** когда мяч выходит за границы игрового поля
