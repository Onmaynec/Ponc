# Ponc 1.6.0 — Arena Trials

Ponc — браузерная аркада в стиле Pong с полноценными одиночными и локальными матчами на двоих, управлением мышью, клавиатурой и сенсорным экраном. Игра использует HTML Canvas 2D, JavaScript ES Modules и Vite; онлайн-сервер не требуется.

## Быстрый запуск

Требуется Node.js 22.12+.

```powershell
git clone -b feature/arena-trials-1.6 https://github.com/Onmaynec/Ponc.git
cd Ponc
npm ci
npm run dev
```

После объединения этой версии в `main` можно клонировать репозиторий без указания ветки. Vite выводит адрес, по которому игра доступна в браузере.

## Возможности

### Режимы игры

- **Классика:** первым набрать выбранные 5, 7, 11 или 15 очков.
- **Решающее очко:** первое очко определяет победителя.
- **На время:** 90 секунд активного времени, паузы и подачи не учитываются; при ничьей — овертайм до первого гола.
- **Выживание (новое):** каждый забитый гол увеличивает результат; после 3 пропущенных испытание заканчивается. Рекорды сохраняются только для одиночной игры.

Во всех режимах можно играть против ИИ (Новичок / Стандарт / Эксперт) либо локально вдвоём. В испытании на двоих задача игрока 1 — набрать максимум очков до трёх голов игрока 2.

### Арены (новое)

- **Classic:** свободное поле без препятствий.
- **FLUX:** по центру движется отражатель, который меняет траекторию мяча. Скорость отражателя — 118 единиц/с, размер — 16 × 92. В HUD видны удары о препятствие, бампер подсвечен и имеет отдельный звук.

### Усиления

Можно отдельно включить капсулы бонусов. Капсула достаётся игроку, который последним отбил мяч, когда мяч коснётся капсулы.

| Бонус      | Действие                                                        |
| ---------- | --------------------------------------------------------------- |
| XL-ракетка | Увеличивает высоту с 80 до 120 на 7 секунд                      |
| Турбо      | Ускоряет мяч до 35%, максимум 600 единиц/с                      |
| Энергощит  | Отражает один удар у своих ворот (действует не дольше 9 секунд) |

Капсулы появляются через 3 секунды активной игры, потом через 5 секунд после сбора или исчезновения, и живут 8 секунд.

### Прогресс

- История до 50 завершённых матчей и пять последних игр на главной странице.
- Одиночная карьера: матчи, победы, процент побед (испытания на выживание не учитываются как поражения).
- Пять достижений.
- Survival: лучший результат, количество забегов и пять лучших результатов (хранится до 30 последних).
- Сохранение настроек матча, звука и одной из трёх тем (Неон / Ретро / Монохром) в `localStorage`.

### Управление

| Сценарий                     | Управление                                           |
| ---------------------------- | ---------------------------------------------------- |
| Один игрок                   | Мышь, ↑ / ↓, касание                                 |
| Локально вдвоём              | Игрок 1: W/S; игрок 2: ↑/↓                           |
| Локально на сенсорном экране | Независимое касание по левой и правой половинам поля |
| Пауза                        | Esc или кнопка                                       |
| Перезапуск                   | R или кнопка                                         |

При потере фокуса игра ставится на паузу.

## Архитектура

```text
src/
├── config/          параметры физики
├── core/            матч, очки, правила, события, история и личные рекорды
├── entities/        мяч и ракетки
├── systems/         физика, ИИ, ввод, арены, усиления и звук
├── rendering/       Canvas 2D и игровые эффекты
└── ui/              меню, HUD, статистика и CSS
tests/               Node.js unit и integration
e2e/                 Playwright браузерные тесты
```

Игровая симуляция выполняется с фиксированным шагом 1/120 секунды. Движение FLUX, игровое время и длительность бонусов привязаны к этому шагу; они не продолжаются при паузе. Система не требует никакого платного API.

## Проверка сборки

```bash
npm ci
npm run lint
npm run format:check
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Для публикации на статическом хостинге используйте содержимое `dist/` после `npm run build`. Vite использует относительный `base: './'`.

**Ограничения:** нет сетевых матчей и синхронизации прогресса между устройствами. Таблицы рекордов локальные, без проверки со стороны сервера.
