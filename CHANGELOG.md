# Changelog

Все значимые изменения проекта Ponc фиксируются в этом файле.

## [1.1.0] — 2026-07-25

### Added

- Модульная архитектура ES Modules с каталогами `src/config`, `src/core`, `src/entities`, `src/systems`, `src/rendering` и `src/ui`.
- Независимые `GameCore`, `GameStateMachine`, `EventBus`, `PhysicsSystem`, `InputSystem`, `AISystem`, `CanvasRenderer` и `GameUI`.
- Fixed timestep 120 Гц, ограничение большого frame delta и лимит catch-up обновлений.
- Централизованная конфигурация размеров, скоростей, углов, winning score и countdown.
- События гола, подачи, паузы, продолжения, сброса и завершения матча.
- Vite, ESLint, Prettier, Playwright и npm scripts с закреплёнными версиями инструментов.
- GitHub Actions CI для `push` и `pull_request` в `main`.
- Unit, integration и browser smoke-тесты, включая имитацию 60/120/144 Гц.
- Контролируемое сообщение при ошибке загрузки или инициализации приложения.
- Отображение версии из `package.json` в UI и диагностике.

### Changed

- Скорости мяча и ракеток переведены из единиц на кадр в логические единицы в секунду.
- Отрисовка теперь только читает снимок игрового состояния.
- InputSystem формирует нормализованные команды и не перемещает ракетку напрямую.
- AI получает только снимок состояния и не зависит от DOM.
- Приложение запускается через Vite или другой HTTP server с поддержкой ES Modules.

### Preserved

- Все правила и пользовательские сценарии версии 1.0.1: матч до 11 очков, countdown, пауза, reset, pointer/keyboard input, автоматическая пауза и устойчивые столкновения.

## [1.0.1] — 2026-07-25

### Added

- Явная модель состояний: `MENU`, `COUNTDOWN`, `PLAYING`, `PAUSED`, `GAME_OVER`.
- Двухсекундный обратный отсчёт перед первой подачей и после каждого гола.
- Экран результата, пауза и автоматическая пауза при потере фокуса.

### Fixed

- Завершение матча строго при 11 очках.
- Масштабирование координат указателя, приоритет последнего способа ввода и устойчивость столкновений.
